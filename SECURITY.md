# Security Policy

This is a pre-alpha reference, not a production system. There are no network endpoints, private credentials, persistence layer or external AI calls in the shipped code.

Please **do not** publish sensitive exploit details or personal data in a public issue. Open a GitHub issue with non-sensitive reproduction information, or contact the repository owner through an appropriate private GitHub channel if sensitive coordination is required. There is no published security response SLA yet.

Do not commit `.env` files, tokens, user-identifying relationship data, medical data or private ephemeris packages. Remove credentials from the git history and revoke them immediately if accidentally exposed.
