# Contributing to ASTREA Oracle Core

Thank you for helping improve the public core. By contributing you agree that your original contributions will be distributed under Apache-2.0, or that you have rights to contribute compatible material. Do not copy proprietary sources, third-party astrology datasets or commercial application assets.

1. Open an issue to discuss nontrivial changes, describe scope and intended benefit.
2. Fork the project and create a focused branch.
3. Add tests and documentation with each behavior change.
4. Run `python -m unittest discover -s tests -v` locally.
5. Open a pull request explaining the change, safety implications, and backward compatibility.

**Review principles:** prefer transparent calculations, reproducible evidence, no prediction marketing, minimized data, and clear rejection of consequential profiling. Maintainers decide the roadmap; there are no promised response times yet.
