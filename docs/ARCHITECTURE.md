# Architecture and trust boundaries

ASTREA provides a reference workflow for opt-in adult social compatibility experiments.

1. Profiles include anonymous identifiers, adult age, explicit consent, declared values and interests, and optional zodiac labels.
2. Deterministic Jaccard overlap yields a demonstrative and explainable score. It is not a likelihood or scientific relationship prediction.
3. Zodiac labels produce optional symbolic creative notes only and never influence the score.
4. A Narrator protocol supports future models, subject to separate consent and redaction controls.
5. Actual platforms need access control, deletion, abuse reporting, audits, age assurance and privacy compliance.

The core performs no HTTP requests or data persistence. No medical, employment, lending, security, policing or similar consequential decisions are supported.
